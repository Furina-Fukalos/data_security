# 数据安全评估准则 Excel 导入设计说明

> 目标：将《数据安全评估评估准则v1-20260525.xlsx》等准则文件一键导入数据安全评估系统，
> 实现「准则模板更新」与「示例评估项目导入」两种能力。
> 对应实现：`js/criteria-import.js`、`scripts/import_criteria.py`。

---

## 1. 背景

系统内置 477 项评估准则模板（`js/template.js` / `data/template_data.json`），每条包含：
`l1`（一级指标/维度）、`l2`（二级指标/章节）、`l3`（三级指标）、`guidance`（评估指引）、`applicable`（适用对象）。

《数据安全评估评估准则v1-20260525.xlsx》是同一套准则的**增强版**：

| 维度工作表 | 数据行数 | 内置模板对应索引 |
|---|---|---|
| 一、数据安全管理 | 134 | 0 – 133 |
| 二、数据处理活动 | 163 | 134 – 296 |
| 三、数据安全技术 | 94 | 297 – 390 |
| 四、个人信息保护 | 86 | 391 – 476 |
| 合计 | **477** | 0 – 476 |

（另有「结果统计-一级指标」「结果统计-二级指标」两个统计工作表，属于结果数据，系统自行计算，不导入。）

### 实测对齐结果（openpyxl 与 SheetJS 双引擎验证）

- 条数：477 / 477 完全一致；
- 一级/二级/三级指标树结构：**0 处不一致**；
- 评估指引文本：**0 处不一致**（逐字相同）；
- 新增字段：评估位置 391 条、评估实施 13 条（仅工作表一含该列）；
- 适用对象标注：12 处与内置不同（以文件为准，修正更准确）；
- 示例评估记录 85 条、判定结果 372 条（符合 47 / 基本符合 263 / 不符合 7 / 不适用 55 / 未填 105）。

结论：文件与内置模板按「工作表顺序 + 索引」一一对应，可直接安全映射。

---

## 2. 总体设计

导入一次解析，提供两种独立动作（可同时勾选）：

1. **① 更新评估准则模板**
   - 为对应索引的内置条目补充 `position`（评估位置/取证位置）与 `implement`（评估实施方法）；
   - 以文件为准修正 `applicable`（适用对象）；
   - 覆盖数据持久化到 `localStorage`（键 `data_security_criteria_v1`），页面刷新后仍生效；
   - 提供「恢复内置」一键还原。

2. **② 导入为评估项目**
   - 创建新项目，将文件中的 `record`（评估记录）与 `result`（判定结果）按索引填入 `project.items`；
   - 判定结果归一化：`基本符合 → 部分符合`；保留 `不适用`；
   - 未填写判定结果的条目保持「未评估」。

### 判定结果归一化规则

| 文件值 | 系统值 | 说明 |
|---|---|---|
| 符合 | 符合 | — |
| 基本符合 | **部分符合** | 术语归一化（统计工作表口径一致） |
| 不符合 | 不符合 | — |
| 不适用 | **不适用** | 系统新增第 4 种判定值，评分时不计入 X/Y/Z 与总分（与文件统计口径一致） |
| （空） | （空） | 未评估 |

### 「不适用」的系统级支持（本设计新增）

为忠实呈现文件内容，系统全面支持「不适用」判定值：

- 指标弹窗判定下拉增加「⛔ 不适用」；树形状态徽章增加灰色 `na` 样式；
- 项目统计卡、仪表盘统计、柱状图/饼图/雷达图增加「不适用」口径；
- 评分公式保持 `S = 100 × (X + 0.5Y) / (X + Y + Z)`，**不适用项从分母中剔除**（源文件统计口径：如「数据安全管理」134 项中 38 项不适用，仅 96 项参与评分）；
- Excel 导出结果列增加「不适用」灰色样式与统计行。

## 3. 关键实现

### 3.1 解析（浏览器端，SheetJS）

`parseCriteriaWorkbook(arrayBuffer)`：

1. `XLSX.read(buffer, {type:'array'})` 读取工作簿；
2. 跳过工作表名含「结果统计」的工作表；
3. 对每个维度工作表：
   - `criteriaSheetToRows`：读取全部单元格，按 `ws['!merges']` 将合并区域左上角值**前向填充**到整块区域（一/二/三级指标列均为纵向合并）；
   - 在前 5 行内定位含「评估指引」的表头行，按列名映射字段（兼容工作表一多出的「评估实施」列）；
   - 逐行提取 `{seq, l1, l2, l3, guidance, position, implement, applicable, record, result}`，跳过指引为空的空行。

### 3.2 对齐校验与覆盖构建

`matchCriteriaToTemplate(parsed)`：按展平顺序与 `TEMPLATE[idx]` 逐条比对
（l1/l2/l3 树结构、guidance 文本），生成校验报告（条数、结构不一致数、指引不一致数、
position/implement/applicable/record 统计、判定分布）。

`buildCriteriaOverrides(parsed)`：仅当树结构匹配时，生成 `{idx: {position?, implement?, applicable?, guidance?}}`
覆盖映射（applicable 与内置不同才写入；guidance 不同才写入；position/implement 非空才写入）。

### 3.3 持久化与应用

- 存储：`localStorage['data_security_criteria_v1'] = {version, source, importedAt, itemCount, overrides}`；
- 应用：`applyStoredCriteria()` 在 `init.js` 启动时与导入确认时调用，就地更新全局 `TEMPLATE`（各模块均引用该数组，无需改名）；
- 还原：`restoreBuiltinCriteria()` 依据加载时捕获的 `BUILTIN_TEMPLATE` 快照还原四个字段并清除存储。

### 3.4 导入为项目

`buildProjectFromCriteria(parsed, fields)`：

- 展平 477 条 → `project.items[idx] = {record, result, applicable_override}`；
- 结构不匹配的条目保留「未评估」；
- 补齐全部 477 项；项目携带 `criteriaSource`（来源文件名）。

### 3.5 权限

导入入口 `showCriteriaImportModal()` 要求 `manage_projects` 权限（评估组长/系统管理员）；
「导入为评估项目」动作要求 `create` 权限；「更新准则模板」动作要求 `manage_projects`。

## 4. 界面交互

1. 仪表盘「评估项目列表」卡片头部新增 **📥 导入准则Excel** 按钮；
2. 弹出导入对话框：
   - 顶部说明 + 文件选择 + 当前准则状态（内置 / 已导入·来源，可「恢复内置」）；
   - 解析后展示识别结果：工作表明细、对齐校验、位置/实施/适用对象/记录统计、判定分布；
   - 两种导入方式复选框（默认全选）+ 项目信息表单（名称/对象/人员/日期/适用对象预设）；
3. 确认后按勾选执行，创建项目则自动打开该项目。

## 5. 使用步骤

### 方式一：浏览器内导入（推荐）

1. 以评估组长/系统管理员登录；
2. 仪表盘点击「📥 导入准则Excel」→ 选择《数据安全评估评估准则v1-20260525.xlsx》；
3. 查看识别结果（477 项、完全对齐、391 条位置提示等）；
4. 勾选「更新评估准则模板」和/或「导入为评估项目」，填写项目信息后确认；
5. 模板更新即时生效（刷新后仍保留，可在对话框「恢复内置」还原）；
   若导入为项目，自动打开新项目，可继续完善评估。

### 方式二：离线脚本（管理员）

```bash
python scripts/import_criteria.py                  # 仅校验并输出报告
python scripts/import_criteria.py --emit-json      # 同步 data/template_data.json（供 export_excel.py 使用）
python scripts/import_criteria.py --emit-js        # 覆盖内置模板 js/template.js（谨慎）
```

## 7. 边界与说明

- **同源版本**：文件须为同一套 477 项准则；若结构不一致（树结构错位），模板更新会跳过不匹配条目，
  项目导入对不匹配条目保留「未评估」，并在预览中给出警告；
- **存储位置**：模板覆盖与项目数据均存于浏览器 localStorage（file:// 场景可用），
  换浏览器/清除数据后需重新导入；
- **统计工作表**：不导入（系统实时计算）；
- **适用对象**：以文件标注为准（12 处修正，覆盖系统内置，如 idx0 的说明性噪声文本被清除）。
